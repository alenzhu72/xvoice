# 声线工坊 · .NET 8 GPU 还原测试版

完整解压后打开 VoiceChange.RvcGpu.exe，选择 GPU DirectML 和音色。
自带 .NET 8、ONNX Runtime 和 DirectML，实时变声使用 C# 和本机 GPU。

默认与之前截图对齐：音高 +13 半音，RMVPE，检索混合 0.35，
130 ms 音频块，80 ms 淡化，2 秒上下文，44100 Hz 输出，
响度混合 0.5，门限 -60 dB。降噪未开启。

本次进一步移植音频块对齐、窗函数 sinc 重采样、逐段 RMS 响度包络，
并导入原始 FAISS 聚类中心与检索向量。索引检索在 C# 中执行。
实现仍与 Python/Torchaudio 有差异，不能承诺波形或听感完全相同。

## 添加以前训练的音色

点击“导入新音色”，选择以前训练输出的 .pth，或 CSharp 目录中的 .onnx。
- 本版规格的 ONNX 搭配同名 .ivf，可直接复制导入。
- 旧规格 ONNX 会自动查找上一级同名 PTH，也可以手动选择原始 PTH。
- 配套原始 .index 会自动查找，找不到时弹窗选择。
- 第一次转换调用开发电脑已有的 RVC Python 环境和导出依赖。
  转换完成后的日常变声使用 .NET。分发给别人时带上转换后的 ONNX/IVF 即可。
- 若自动找不到开发环境，会要求选择含 runtime/python.exe 的 RVC 根目录，
  以及 obj/rvc-export-deps 或训练器内的 export-deps。
- 支持 RVC v1、带 F0、256 维特征。请使用来源可信的训练检查点。
- 转换错误日志保存在提示中的临时目录。

同名音色不覆盖，可以先给模型及配套索引使用另一组同名文件名。
包内五个音色已按本版规格转换，可直接选择。
